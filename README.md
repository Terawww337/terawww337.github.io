# Terawww

Official developer portfolio: https://terawww337.github.io/

Static pages in English, Russian, Ukrainian, Polish, German, Spanish, Japanese and Simplified Chinese. The root detects browser language; explicit locale URLs and footer links preserve the selected language. English is the fallback. Each page has a self canonical, reciprocal hreflang and an x-default link.

The original desktop design, fonts, rain, cursor and hover glitch are retained. Mobile CSS keeps all navigation links available, fits content into narrow screens, permits browser zoom and uses 44 px touch targets. Matrix playback pauses in hidden tabs and respects reduced motion.

The supplied pixel PNG is used only for favicon/device shortcut assets; it is not displayed in page content. Social cards use the developer wordmark. Person/ProfilePage/WebSite/VideoGame structured data connects Terawww (Teraw, Терав, Тераввв) with WriteNor. No prices, release dates, ratings or reviews are invented. The Last Command is identified as a WriteNor prototype per the creator.

Google verification remains in place. Submit https://terawww337.github.io/sitemap.xml in Google Search Console and inspect the home page after deployment. Google chooses ranking, snippets and favicon display; markup does not guarantee special search features.
